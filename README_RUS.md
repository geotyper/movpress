# MovPress

[English version](README.md)

MovPress — небольшое приложение для macOS, предназначенное для сжатия записей экрана и создания оптимизированных GIF. Интерфейс построен на Qt 6, а обработка видео выполняется установленными в системе инструментами `ffmpeg` и `ffprobe`.

## Возможности

- Экспорт в MP4/H.264 или GIF с адаптивной палитрой
- Встроенное воспроизведение исходного и готового видео
- Предпросмотр и параметры сжатия в двухколоночном интерфейсе
- Визуальный выбор начала и конца фрагмента
- Воспроизведение предпросмотра только в пределах выбранного фрагмента
- Ручная настройка времени начала и длительности
- Выбор разрешения, FPS, CRF и пресета кодирования
- Сохранение или удаление звука
- Настраиваемое кадрирование видео
- Готовые профили для YouTube, Хабра, Telegram и максимального сжатия
- Выбор видео перетаскиванием
- Точный прогресс конвертации с помощью `ffprobe`
- Сравнение размера до и после сжатия и процент экономии
- Отмена конвертации
- Открытие результата и показ файла в Finder
- Запоминание последних настроек и использованной папки
- Предупреждение перед перезаписью и при нехватке свободного места

## Требования

- macOS
- CMake 3.21 или новее
- Компилятор с поддержкой C++20
- Qt 6.5 или новее с модулями Widgets, Multimedia и MultimediaWidgets
- `ffmpeg` и `ffprobe` в `PATH`, `/opt/homebrew/bin` или `/usr/local/bin`

## Сборка

Установка зависимостей через Homebrew:

```bash
brew install qt ffmpeg
```

Настройка и сборка приложения:

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build
open build/MovPress.app
```

Если Qt установлен официальным установщиком, можно вызвать его `qt-cmake` напрямую:

```bash
/путь/к/Qt/6.x.x/macos/bin/qt-cmake -S . -B build
cmake --build build
open build/MovPress.app
```

## Использование

1. Перетащите видео в окно приложения или выберите его через диалог.
2. Просмотрите видео и выберите нужный фрагмент.
3. Выберите готовый профиль или настройте параметры сжатия вручную.
4. Укажите путь для результата и запустите конвертацию.
5. Просмотрите готовый файл, откройте его или покажите в Finder.
