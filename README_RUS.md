# MovPress

[English version](README.md)

**[Скачать для macOS (Apple Silicon)](https://github.com/geotyper/movpress/releases/latest)**

Распакуйте архив и откройте `MovPress.app`. `ffmpeg` и `ffprobe` уже внутри. Если macOS пишет, что приложение повреждено, выполните в этой папке `xattr -dr com.apple.quarantine MovPress.app` и откройте его снова.

**[Скачать для Windows (amd64)](https://github.com/geotyper/movpress/releases/latest/download/MovPress-windows-amd64.zip)**

Распакуйте архив и запустите `MovPress.exe`. Qt, `ffmpeg` и `ffprobe` лежат в той же папке.

MovPress — небольшое приложение для сжатия записей экрана и создания оптимизированных GIF. Интерфейс построен на Qt 6, а обработка видео выполняется `ffmpeg` и `ffprobe`. Пакеты для macOS и Windows уже содержат эти инструменты.

![Окно приложения MovPress](docs/screenshot.png)

## Возможности

- Экспорт в MP4/H.264 или GIF с адаптивной палитрой
- Встроенное воспроизведение исходного и готового видео
- Предпросмотр и параметры сжатия в двухколоночном интерфейсе
- Визуальный выбор начала и конца фрагмента
- Выбор диапазона по времени или с точностью до кадра
- Воспроизведение предпросмотра только в пределах выбранного фрагмента
- Ручная настройка времени начала и длительности
- Выбор разрешения, FPS, CRF и пресета кодирования
- Аппаратные кодировщики H.264, если их сообщает вложенный или установленный `ffmpeg`
- Сохранение или удаление звука
- Настраиваемое кадрирование, в том числе рамкой прямо на превью
- Готовые профили для YouTube, Хабра, Telegram и максимального сжатия
- Выбор видео перетаскиванием
- Точный прогресс конвертации с помощью `ffmpeg`
- Сравнение размера до и после сжатия и процент экономии
- Отмена конвертации
- Открытие результата и показ файла в Finder или Проводнике
- Запоминание последних настроек и использованной папки
- Интерфейс на английском и русском языках
- Системная, светлая и тёмная темы оформления
- Предупреждение перед перезаписью и при нехватке свободного места

## Требования

- macOS или Windows
- CMake 3.21 или новее
- Компилятор с поддержкой C++20
- Qt 6.5 или новее с модулями Widgets, Multimedia и MultimediaWidgets
- `ffmpeg` и `ffprobe` во время сборки, чтобы скопировать их в приложение, либо в `PATH`, `/opt/homebrew/bin` или `/usr/local/bin` при запуске

## Сборка

Установка зависимостей через Homebrew:

```bash
brew install qt ffmpeg
```

Настройка и сборка приложения:

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build
open build/MovPress.app
```

Если Qt установлен официальным установщиком, можно вызвать его `qt-cmake` напрямую:

```bash
/путь/к/Qt/6.x.x/macos/bin/qt-cmake -S . -B build
cmake --build build
open build/MovPress.app
```

## Тесты

В проект добавлены небольшие Qt Test-проверки нормализации диапазона, границ кадрирования, выравнивания пикселей и построения видеофильтров FFmpeg:

```bash
cmake -S . -B build -DBUILD_TESTING=ON -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build
ctest --test-dir build --output-on-failure
```

## Использование

1. Перетащите видео в окно приложения или выберите его через диалог.
2. Просмотрите видео и выберите нужный фрагмент.
3. Выберите готовый профиль или настройте параметры сжатия вручную.
4. Укажите путь для результата и запустите конвертацию.
5. Просмотрите готовый файл, откройте его или покажите в Finder или Проводнике.

По умолчанию приложение запускается на английском языке. В верхней части панели настроек выберите `Language`, чтобы переключиться между английским и русским. Для применения нового языка MovPress автоматически перезапустится.

## Настройки

MovPress сохраняет параметры в читаемом файле `movpress.ini` внутри каталога конфигурации приложения, который определяет Qt. В macOS этот каталог находится в пользовательской папке `~/Library/Preferences`. Точный путь на текущем компьютере показывается во всплывающей подсказке при наведении на выбор темы.

При первом создании INI-файла прежние настройки из системного хранилища macOS переносятся автоматически.
