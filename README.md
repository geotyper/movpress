# MovPress

Небольшое macOS-приложение для сжатия записей экрана и создания GIF. Интерфейс построен на Qt 6, кодирование выполняет установленный в системе `ffmpeg`.

## Возможности

- MP4/H.264 и GIF с адаптивной палитрой
- обрезка по началу и длительности
- выбор ширины, FPS, CRF и пресета кодирования
- удаление или сохранение аудио
- drag-and-drop исходного видео
- отмена конвертации
- готовые профили для YouTube, Хабра и Telegram
- визуальный выбор начала и конца фрагмента
- точный прогресс обработки через `ffprobe`
- сравнение размера до и после сжатия
- открытие результата и показ файла в Finder

## Зависимости и сборка

На текущей машине Qt установлен в `/Users/geotyper/QT/6.12.0/macos`:

```bash
/Users/geotyper/QT/6.12.0/macos/bin/qt-cmake -S . -B build
cmake --build build
open build/MovPress.app
```

На другой машине Qt можно установить через Homebrew и передать его путь в CMake:

```bash
brew install qt
cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build
```

Также в `PATH` должен быть доступен `ffmpeg`.
